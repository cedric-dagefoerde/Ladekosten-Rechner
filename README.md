# Ladekosten-Rechner Web-App

[Hier die Web-App ausprobieren](https://cedric-dagefoerde.github.io/Ladekosten-Rechner/Aufgabe-3/)

## Was macht die Web-App?

Mit dieser Web-App kann man sich die Ladekosten, die gelandene Energiemenge und die Ladedauer berechnen lassen, indem man die Akkugröße, den aktuellen und den gewünschten Ladestand, den Strompreis und die Ladeleistung eingibt.
Die berechneten Ladevorgänge lassen sich anschließend in einer Liste speichern, dauerhaft im Browser sichern, als JSON exportieren und bei Bedarf einzeln oder komplett wieder löschen.
